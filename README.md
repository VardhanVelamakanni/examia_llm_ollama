##  Exam Helper AI (Under Development)

This project is an AI-powered exam preparation assistant designed to help students make better use of their own study materials. Users can upload PDF or PPT files related to a subject, and the system analyzes the content to generate exam-oriented questions, concise answers, and basic topic-wise explanations.

The primary goal of this project is to reduce exam preparation time by identifying important concepts and framing likely exam questions directly from the uploaded study material.

### Current Features
- Reads and processes PDF and PPT files
- Generates exam-style questions from the content
- Provides short, clear answers for revision
- Produces basic topic-wise explanations
- Runs fully offline using a local LLM (no API keys or paid APIs)

### Project Status
This project is **under active development**. The implementation, prompts, and architecture are subject to change as the system evolves and improves.

### Planned Enhancements
- Improved topic structuring and hierarchy
- Difficulty-based question generation
- Web interface for file uploads and results
- Enhanced handling of visual and diagram-based content

This repository represents an evolving, student-focused solution rather than a finalized product.
